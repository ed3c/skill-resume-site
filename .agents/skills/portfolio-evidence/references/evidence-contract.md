# Public evidence contract

## Public

- Transferable capability summaries.
- Public repositories owned by `ed3c`.
- Evidence states and current limitations.
- Remote work and commercial terms.
- Architecture and execution methods that do not expose confidential bindings.

## Private

- Employer, company, customer, or product identities.
- Credentials, signing material, device identifiers, or internal endpoints.
- Private repository URLs.
- Vendor bindings, paid-library inventory, and proprietary adapters.
- Unverified adoption, revenue, uptime, speed, quality, or performance claims.

The release gate must fail when a private project has a URL or a public project points outside `github.com/ed3c/`.
