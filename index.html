WHY NOW

Code generation is abundant.
Reliable execution is not. 程式碼生成已普及。
可靠執行仍然稀缺。

The valuable layer now sits around the model: reusable Skills, tool boundaries, deterministic checks, durable state, and proof that a task really finished. 現在真正有價值的層位於模型周圍：可重用 Skills、工具邊界、確定性檢查、持久狀態，以及任務確實完成的證明。

This portfolio presents that layer as a service, not as a list of prompts. 這份履歷把這一層當成可交付服務，而不是提示詞清單。

OFFICIAL PATTERN

Anthropic Evaluator–Optimizer

Generate→Evaluate→Feedback↺

One model produces a candidate. An evaluator supplies feedback. The generator revises when clear criteria support iteration.一個模型產生候選結果，Evaluator 提供回饋；在具備明確標準時，Generator 反覆修正。

DELIVERY SPECIALIZATION

Eeon Small Execution Loop

Spec→Change→Execute→Assert→Repair↺

The evaluator is primarily deterministic: tests, type checks, linters, policy gates, and evidence receipts. An LLM critique can assist, but it cannot create release truth.Evaluator 以確定性機制為主：測試、型別檢查、Lint、Policy Gate 與證據收據。LLM 評語可輔助，但不能建立 Release Truth。
